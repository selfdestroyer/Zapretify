# Changelog

All notable changes to the Zapretify project are documented in this file.

## [1.3.2] - 2026-10-18

### Безопасность и целостность данных
- **Потокобезопасный доступ к конфигурации**: метод `app.GetConfig()` возвращает изолированную копию (`Clone()`), а все модификации изолированы внутри `config.Get().Update(...)` под блокировкой мьютекса, исключая гонки данных.
- **Глубокая валидация и защита от инъекций**: введены проверки `GameFilterTCP` и `GameFilterUDP` (числовые диапазоны 1-65535, не более 16 диапазонов, запрет пробелов и флагов); санитизация аргументов в `BuildArgs` предотвращает внедрение параметров в командную строку `winws.exe`.
- **Обязательный секрет и валидация доменов**: запрещен пустой секрет Telegram-прокси; домены `CFWorkerDomain` и `CFUserDomain` валидируются как корректные hostname без схем и путей.
- **Фиксация источника обновлений**: репозиторий GitHub зафиксирован константой `DefaultGithubRepo = "selfdestroyer/Zapretify"`, предотвращая подмену источника бинарных обновлений через API.

### Списки и файловая система
- **Защита от зарезервированных имен Windows**: в `cleanPath` имя файла проверяется до первой точки, блокируя обход через `CON.foo.txt` и подобные DOS-устройства.
- **Белый список списков**: разрешены только доверенные стандартные списки и файлы пользователя `*-user.txt`.
- **Атомарная запись и лимит размера**: запись файлов списков переведена на временный файл с последующим переименованием (`temp+rename`) и жестким лимитом размера 5 МБ.

### Сеть и системные компоненты
- **Строгая валидация схем `tg://`**: разрешены исключительно безопасные хосты `proxy`, `resolve`, `join`.
- **Выгрузка WinDivert при установке и обновлении**: установщик (`Zapretify-Setup.exe`) и механизм in-place обновления принудительно останавливают и удаляют службу драйвера WinDivert, исключая ошибку блокировки `WinDivert64.sys`.
- **Контекст завершения сессий MTProto**: вызовы `handleClient` и циклы обработки получают контекст сервера и моментально прерываются при остановке.

## [1.3.1] - 2026-10-18

### Процессы и стабильность
- **Мониторинг winws.exe**: добавлена горутина `cmd.Wait()` в `core/zapret/process.go`. При сбое или внешнем завершении `winws.exe` статус в UI обновляется автоматически, очищается активная стратегия и удаляется PID-файл.
- **Безопасная зачистка орфанов (`CleanupOrphans`)**: перед `taskkill` проверяется имя исполняемого файла процесса (`winws.exe`), предотвращая завершение сторонних процессов при переиспользовании PID операционной системой.

### Telegram MTProto Прокси
- **Корректный парсинг секретов**: удаление транспортных префиксов `dd`/`ee` производится строго при длине 34 символа, сохраняя 32-байтные секреты.
- **Маскирование ключей в логах**: секрет скрывается в журналах как `dd1234***`.
- **Принудительный разрыв активных сессий**: при остановке Telegram-прокси все открытые клиентские соединения закрываются немедленно, предотвращая зависание Telegram.

### Конфигурация и миграция
- **Миграция старых конфигураций**: `config.Load()` автоматически исправляет и нормализует параметры старых версий (v1.2.2), предотвращая сбои валидации.
- **Синхронизация версии**: единая константа `config.Version = "1.3.1"` во всем проекте.

### Интерфейс (UI)
- **Обработка ошибок API**: все мутирующие операции используют обертку `api()` с проверкой `res.ok` и выводом сообщений об ошибках в тосты.
- **Поддержка F5 и sessionStorage**: токен сессии кэшируется в `sessionStorage`, предотвращая ошибку 401 при обновлении страницы; акселераторы F5/Ctrl+R перехвачены.

## [1.3.0] - 2026-10-17

### Стабильность и системные улучшения
- **Улучшенный запуск (Single Instance)**:
  - Проверка уже запущенной копии программы теперь выполняется до запроса повышения прав (UAC). Повторный запуск моментально разворачивает существующее окно приложения без всплывающих системных диалогов.
  - Исключен ошибочный захват окон проводника Windows с именем папки «Zapretify».
- **Изолированное управление процессами**:
  - Реализован точечный учет идентификатора процесса (PID) в `winws.pid`. Приложение завершает исключительно собственные процессы `winws.exe`, предотвращая случайное закрытие сторонних утилит (GoodbyeDPI, Flowseal).
  - Добавлен механизм автоматической зачистки фоновых процессов (`CleanupOrphans`) при следующем запуске в случае непредвиденного сбоя системы.
- **Инсталлятор и обновление**:
  - Мастер установки поддерживает режим бесшовного обновления поверх существующей версии с сохранением пользовательских списков и конфигурации `config.json`.
- **Надежность настроек**:
  - Применение списков IPSet теперь валидируется до сохранения в конфигурационный файл.
  - Добавлена проверка и корректная обработка ошибок при добавлении в автозапуск реестра Windows.

### Безопасность и API
- **Авторизация локального API**:
  - Добавлена проверка сессионного токена через заголовок `X-Zapretify-Token` с валидацией за константное время. Передача токена через URL отключена для предотвращения его попадания в системные журналы.
  - Добавлена строгая проверка заголовков `Host` и `Origin`, а также метаданных `Sec-Fetch-Site` для защиты от нежелательных межсайтовых запросов из браузера.
  - Маршруты изменения состояния переведены на метод `POST` с установкой лимита на размер входящих данных (1 МБ).
- **Валидация параметров и путей**:
  - Введена проверка стратегий и параметров тестирования по встроенному белому списку реестра.
  - В редакторе списков разрешены только файлы с расширением `.txt` внутри каталога `lists/` с блокировкой обращений к системным устройствам Windows (`CON`, `PRN`, `AUX`, `NUL` и др.) и потокам NTFS.
  - Открытие ссылок переведено на системный вызов Windows `ShellExecuteW` с проверкой доменных имен.
